# 🐱 CAT DASH — Career Maze Challenge

A classroom-friendly career and jobs quiz game built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — main game page
- `style.css` — game design
- `script.js` — questions and game logic
- `assets/` — optional future images/audio

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub + Render
1. Create a GitHub repository.
2. Upload all files and folders from this project.
3. In Render, create a **Static Site** connected to the GitHub repository.
4. Use the repository root as the publish directory.
5. No build command is required.
6. Deploy.

The repository root must contain `index.html`.

## Important
This version is a **local classroom multiplayer-style game**: several teams can play on the same screen/device. It does not yet synchronize players across separate phones.

For true real-time multiplayer across different devices, a backend/server (for example WebSocket or a realtime database) is required.
